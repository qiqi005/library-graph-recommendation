# Library Graph Traversal & Book Recommendation Engine
A Java graph-theory application leveraging BFS and DFS algorithms to build a book recommendation network and reference path exploration engine.

## Tech Stack & Concepts
- Language: Java
- Algorithms & Data Structures: Graph Theory (Adjacency List), Breadth-First Search (BFS), Depth-First Search (DFS), Queues, Sets.

## Key Features
- Book Network Graph: Models books as nodes and shared reference relationships as edges.
- BFS Recommendation Engine: Executes Breadth-First Search to suggest closely linked reading materials level-by-level.
- DFS Reference Path Exploration: Executes Depth-First Search for deep topic exploration and reference tracing.
